# Retail Sales Analysis

## Project Overview
This project focuses on analyzing retail sales data to understand sales performance, customer behavior, and business trends.

## Tools Used
- Microsoft Excel
- SQL
- Power BI

## Project Objectives
- Analyze retail sales data.
- Identify sales trends and patterns.
- Analyze total orders and revenue.
- Understand category-wise sales performance.
- Generate meaningful business insights.

## Project Work

### 1. Excel
- Data cleaning and preparation
- Data analysis
- Pivot tables and charts
- Sales dashboard

### 2. SQL
- Data querying
- Data validation
- Duplicate order ID checking
- Sales analysis
- Category-wise analysis

### 3. Power BI
- Interactive dashboard
- Sales performance analysis
- Visual representation of key metrics
- Business insights

## Key Outcomes
- Improved understanding of retail sales performance.
- Identified important sales trends.
- Developed data analysis and visualization skills.

## Conclusion
This project demonstrates practical skills in Excel, SQL, and Power BI for retail sales data analysis.
